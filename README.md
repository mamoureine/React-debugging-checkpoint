# React State & Props Debugging

A small React counter for exploring parent state, props, and component updates.

## Run the app

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The counter starts at zero; use `+` to
increment, `-` to decrement (it stops at zero), and **Reset** to return to zero.

For the debugging walkthrough and React Developer Tools steps, see
[DEBUGGING.md](./DEBUGGING.md).
